# TPaPCC

**Trusted Phone and PC Connection** — приложение для явного, подтверждаемого подключения телефона и ПК/другого устройства.

> Проект находится в разработке. TURN пока намеренно не включён.

## Что уже есть

- 📱 Android-клиент на Kotlin.
- 🔗 Одноразовый 6-значный код сопряжения, действующий 10 минут.
- 🔐 Явное подтверждение входящей удалённой сессии владельцем телефона.
- 📺 WebRTC-сессия для передачи экрана.
- 🧊 Обмен WebRTC-сигналами через Supabase.
- 🤖 Telegram-интерфейс для управления запросами.
- 🛑 Возможность завершить активную сессию с телефона.
- ⚙️ Явные Android-разрешения для экрана, микрофона, уведомлений и Accessibility.

## UI-поведение

### Просто Хост

1. На экране есть только действие **«Создать код»**.
2. После создания код остаётся видимым до подключения/истечения срока.
3. Кнопки управления и блок сессии скрыты до одобренного подключения друга.
4. После подключения они плавно появляются снизу.

### Подключение к другу

1. Показывается только поле 6-значного кода и **«Подключиться»**.
2. Кнопки **«Создать код»** здесь нет.
3. Управление появляется только после активной одобренной сессии.

### Хост через Telegram

Кнопка режима открывает Telegram-бота напрямую. Внутреннее меню приложения для этого режима не открывается.

## Структура

- `app/` — Android-приложение.
- `supabase/functions/tpaPCC-api/` — API, сопряжение, сессии и WebRTC-сигналинг.
- `supabase/functions/tpaPCC-telegram/` — Telegram webhook.
- `telegram-bot/` — документация Telegram-бота.
- `pc-client/` — текущий веб-клиент ПК.
- `.github/workflows/android.yml` — автоматическая сборка debug APK.

## Сборка

    gradle assembleDebug

Готовый APK:

    app/build/outputs/apk/debug/app-debug.apk

GitHub Actions автоматически собирает debug APK при push в `main`.

## Telegram

Токен бота хранится только в Supabase Secret:

    TELEGRAM_BOT_TOKEN

Приложение не получает токен. Для кнопки Telegram API-сервис безопасно запрашивает username бота через `getMe` и возвращает только публичную ссылку `https://t.me/<bot>`.

## Безопасность

TPaPCC не предназначен для скрытого управления устройством:

- владелец подтверждает входящую сессию;
- Android-системные разрешения выдаются вручную;
- срок сессии ограничен;
- команды проверяются по разрешениям сессии;
- секрет Telegram-бота не хранится в APK или Git.

## Текущий статус
